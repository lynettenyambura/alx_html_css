# Smileschool Homepage 

This project is a simple responsive **homepage built with HTML and CSS**, following the **HTML, advanced** concept from the curriculum.  
The focus is **styling and layout implementation** using a provided **Figma design file**.

---

## Project Overview

The **Smileschool Homepage** is a single-page website that introduces users to a fun learning platform about smiling.  
It includes:
- A navigation header with a logo and links
- Hero section with headline, call-to-action, and highlights
- Instructor section ("Learn from the pros")
- Testimonial block
- Most popular tutorials with star ratings
- Free membership highlights
- FAQ section
- Footer with social links

The design was provided in **Figma**, and images were provided for download. The goal was to translate the mockup into semantic and accessible HTML + CSS.
